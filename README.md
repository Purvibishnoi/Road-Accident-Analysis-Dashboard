# Road Accident Dashboard

An interactive **Road Accident Dashboard** built to analyze accident casualties across different dimensions such as severity, vehicle type, road type, road surface, location, and time period.  
This project helps stakeholders identify accident patterns and make data-driven road safety decisions.

## Project Overview

The dashboard presents accident insights for **2021 and 2022**, with a focus on:
- Total casualties.
- Casualties by severity.
- Casualties by vehicle type.
- Monthly trend comparison between current year and previous year.
- Casualties by road type.
- Casualties by road surface.
- Casualties by location and day/night.

The dataset contains **3.07 lakh rows** and **21 fields**, making it suitable for detailed accident trend analysis and dashboard reporting.

## Objectives

The main goal of this dashboard is to:
- Track and analyze road accident casualties.
- Compare accident trends across years.
- Identify high-risk road conditions and vehicle categories.
- Support government and transport-related stakeholders in decision-making.

## Key KPIs

- **Total Casualties**.
- **Fatal Casualties**.
- **Serious Casualties**.
- **Slight Casualties**.
- **Casualties by Car**.

## Dashboard Insights

The dashboard answers questions such as:
- Which vehicle type has the highest casualties?
- How do casualties differ between urban and rural areas?
- What is the monthly trend of casualties in 2021 vs 2022?
- Which road type and road surface are associated with more accidents?
- How do day and night conditions affect casualty numbers?
